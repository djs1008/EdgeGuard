# EdgeGuard

EdgeGuard 是一个面向小型旋转设备的嵌入式边缘智能状态监测与故障诊断项目。项目计划以 STM32F407VGT6 为实时采集与边缘推理节点，使用 ADXL345、INA219 和 DS18B20 获取振动、电流与温度数据，并通过 Orange Pi 3B 完成数据存储、服务与 Web 可视化。

## 当前阶段

项目目前处于 **阶段 0：仓库与文档结构初始化**。

本阶段仅建立目录和规划文档，尚未实现硬件驱动、数据采集、信号处理、TinyML、网关、后端或前端功能。各模块的具体接口、器件引脚和技术选型将在后续阶段根据实物、原理图和实验结果确认。

## 初步系统架构

```text
风扇 / 直流电机
    │
    ├── ADXL345：三轴振动
    ├── INA219：电压与电流
    └── DS18B20：温度
             │
             ▼
       STM32F407VGT6
    数据采集 / 信号处理 / TinyML
             │
       串口（首版规划）
             │
             ▼
          Orange Pi 3B
    数据接收 / 存储 / API / Web
```

以上为初步边界，不代表相关模块已经实现。

## 目录说明

| 目录 | 用途 |
|---|---|
| `firmware/` | STM32 固件工程与后续板级代码 |
| `host-tools/serial-collector/` | 主机端串口数据采集工具 |
| `host-tools/visualization/` | 开发阶段的数据绘图与检查工具 |
| `ml/datasets/` | 数据集说明、清单与小型示例；大型原始数据不直接提交 Git |
| `ml/training/` | 模型训练与实验复现 |
| `ml/evaluation/` | 数据质量和模型评估 |
| `gateway/` | Orange Pi 网关服务 |
| `dashboard/` | Web 可视化界面 |
| `hardware/` | BOM、接线、原理图与后续 PCB 资料 |
| `protocol/` | STM32 与网关之间的通信协议定义 |
| `docs/` | 需求、架构、路线图、测试和开发文档 |

## 后续路线

1. 固化需求、系统边界和测试标准；
2. 验收 STM32F407、供电和调试链路；
3. 逐个实现并验证振动、电流与温度采集；
4. 建立稳定的数据流、串口协议和主机采集工具；
5. 设计实验并建立可复现数据集；
6. 完成信号处理、模型训练和评估；
7. 将量化模型部署至 STM32；
8. 实现 Orange Pi 网关、数据存储与仪表盘；
9. 完成可靠性测试、文档、演示和作品集。
