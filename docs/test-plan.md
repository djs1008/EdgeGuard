# EdgeGuard 测试计划

## 1. 文档状态

- 阶段：阶段 0（初始化）
- 状态：测试策略草案
- 用途：规定后续各层级测试类型、证据和通过原则

当前没有业务实现，因此本文件不包含虚构的测试结果。

## 2. 测试目标

- 验证硬件连接和供电安全；
- 验证传感器测量正确性与错误处理；
- 验证采样实时性、缓冲安全和通信完整性；
- 验证数据质量、模型泛化和 MCU 部署一致性；
- 验证网关存储、API、界面和故障恢复；
- 为 README、作品集和简历中的技术结论提供证据。

## 3. 测试层级

### 3.1 文档与静态检查

- 需求具有编号和可观察验收条件；
- 协议、数据 schema 和模型接口保持一致；
- 不提交密钥、大型数据、编译产物和个人路径；
- 未实现内容明确标为规划。

### 3.2 主机侧单元测试

计划覆盖：

- 协议编码、解析、CRC、粘包、拆包和坏帧恢复；
- 传感器寄存器换算和 CRC；
- 信号处理与模型前处理黄金向量；
- 数据质量检查和按会话划分；
- 网关存储、查询和 API 校验。

### 3.3 板级测试

计划覆盖：

- 电源、电压、极性和共地；
- ST-Link 下载、复位和断点调试；
- LED、串口、时钟和定时器；
- 各传感器独立工作及断开故障；
- PWM/MOSFET 控制与负载安全。

### 3.4 集成测试

计划覆盖：

- 多传感器同时采集；
- 采集、处理、推理和通信协同；
- STM32 到 Orange Pi 的端到端数据链；
- 告警、数据库、API 和仪表盘一致性。

### 3.5 模型测试

计划覆盖：

- 按采集会话隔离训练、验证和测试集；
- 每类 precision、recall、F1 和 confusion matrix；
- 异常检测阈值、误报率和漏报率；
- 不同速度、安装位置和日期的泛化；
- 浮点、量化和 MCU 输出差异；
- 模型大小、RAM、Flash 和推理延迟。

### 3.6 可靠性与故障注入

计划覆盖：

- 串口断开、坏帧、丢帧和重复帧；
- 传感器断开、超时和错误读数；
- 缓冲压力、队列满和处理超时；
- 网关或数据库重启；
- STM32 看门狗与复位原因；
- 8–24 小时稳定运行。

## 4. 安全测试约束

- 首次通电前使用万用表确认 12 V 输出极性；
- 130 电机经 XL4015 从低压起测，不得直接连接 12 V；
- 电机和风扇不得由 STM32 板载电源供电；
- 改线前断电；出现过热、异味或异常噪声立即断电；
- 堵转和过载仅可低压、短时、有人看护，并设置停止条件；
- 任何测试不得以损坏器件作为预期结果。

## 5. 测试记录模板

每项实机测试至少记录：

| 字段 | 内容 |
|---|---|
| 测试编号 | 与需求和阶段关联的唯一编号 |
| 日期与执行人 | 实际信息 |
| 硬件版本 | 板卡、模块和接线版本 |
| 软件版本 | Git 提交、固件、协议和模型版本 |
| 前置条件 | 电源、配置、数据和环境 |
| 操作步骤 | 可重复执行的步骤 |
| 预期结果 | 可观察且有阈值的结果 |
| 实际结果 | 日志、截图、测量或数据文件 |
| 判定 | 通过、失败或阻塞 |
| 问题与跟进 | 缺陷编号和后续动作 |

## 7. 待量化指标

以下阈值必须在后续硬件和基线实验后冻结：

- 允许的采样抖动与丢帧率；
- 传感器校准误差；
- 最大推理延迟、RAM 与 Flash 占用；
- 分类宏 F1 与关键故障召回率；
- 异常检测正常工况误报率；
- 串口重连时间和长期运行标准。
